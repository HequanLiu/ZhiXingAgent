# 声研分析事实与建议分离

目标：修复自由文本摘要混淆计划完成日、启动日及依赖关系的问题，保持既有只读场景与模型供应商解耦。

1. 查询回执保存返回给模型的授权字段快照；运行内核仅承载不透明证据，不理解打样业务。
2. 先测试再实现声研结构化输出验证：只接收订单号、实际版本、节点ID与枚举核实项。拒绝额外事实字段、未知节点、无依据建议及过期版本。
3. 场景根据回执生成业务事实与核实建议；计划完成日期只按完成日期展示，不由模型撰写。页面保留证据版本和只读声明。
4. 运行单元/类型/构建验证；在已授权持续分析的demo内提交一次反馈，验证事件、真实工具调用、结构化结果、页面与业务版本一致。
