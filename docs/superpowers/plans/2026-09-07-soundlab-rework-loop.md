# 退回返工闭环

承接人工验收阶段，保持业务规则在独立服务内，模型只读。

1. 测试权限、必填原因、版本冲突、仅待验收可退回及已验收不可撤销。
2. 新增rework状态和不可覆盖的返工历史；退回时新轮次进度归零，保留历史反馈/上轮数量，后续反馈带轮次标记。订单风险不因退回降级。
3. 复用幂等事务/Outbox发布 `sampling.node.return` 固定能力。模型工具不暴露写能力。
4. 验收弹窗增加退回选项及影响说明；移动端显示原因，历史反馈区标明上一轮，审计记录可查。
5. 结构化模型建议支持确认返工范围和安排，但不发送原因原文；验证真实退回、重新反馈/报完工及重新验收。
