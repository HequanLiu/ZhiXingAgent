# 声研助理事件分析接入

沿用已确认的平台/业务隔离设计及演示订单外发授权。本阶段只读分析，不实现模型写操作、审批或真实 Channel。

1. 新增平台 `analysis_jobs` 持久任务表和任务状态函数。测试先覆盖重复事件去重、失败重试上限、运行恢复及结果证据校验。
2. 将已验证的 SDK 初始化逻辑提取到 `packages/runtime-deepseek`。每次使用独立运行目录，限制执行时间、工具次数和输出长度；只传选定供应商密钥；无业务回执不得保存为成功。
3. 在声研场景构建分析提示和工具描述。订单查询继续经过平台能力网关，业务领域留在场景包内。只传此前授权的演示字段，不传客户、反馈原文。
4. Worker 同事务保存活动、分析任务和事件游标；独立循环执行模型任务，单实例锁避免重复消费，失败退避最多3次，重启恢复任务。业务同步不等待模型。
5. API 暴露任务状态、模型摘要、证据版本；SSE 包含任务变更。桌面显示等待/分析中/失败/完成及来源版本，保留人工反馈入口。
6. 运行单元/数据库集成测试、类型检查、构建；启动服务，在演示订单上提交一次真实反馈，验证模型任务、业务回执、页面更新和持久化。记录尚未覆盖的限制。
